# Surface: cockpit concept — console home (alternate)

Scope: local demo only, synthetic data, not deployed. Home page on desktop and phone, plus a true-black idle mode. Mode: operate.

Audience/job: the console's sole operator glancing to learn whether every system is healthy, what needs him, and the exact time to hack a mechanical watch. LCD laptop display for idle; burn-in is not a constraint.

Chosen direction: panoramic cockpit display (the roll), with the bezel-MFD soft-key grammar carried into each portal. Memorable moment: a spinnable 3D wireframe airframe whose systems light in each module's status colour.

## Direction contract

THESIS: The console as one wide glass cockpit panel — portals on true black, status as symbology — refusing the rounded status-card grid.

OWN-WORLD: #000 everywhere; 1px stroke portals with bezel corners; B612 Mono data, Departure Mono soft-keys; colour law: cyan own-ship and selected soft-key, green normal, amber caution, red warning, magenta commanded; text white unless stateful.

STORY: He sees master caution dark and every system green, reads the time to the second, drags the airframe, and taps a soft-key to open one system.

FIRST VIEWPORT: Top band with master caution/warning lamps; left clock portal with seconds tape and HACK; centre 3D airframe with callouts; right systems stack billed by severity; bottom instrument strip.

FORM: panoramic cockpit display, list position 3, seed 78f540ed.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
